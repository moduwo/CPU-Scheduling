# CPU-Scheduling
Develop a CPU scheduling simulator that implements four scheduling algorithms and evaluates their performance using different process workloads. Demonstrate understanding of process scheduling, preemption, ready queues, and scheduling performance metrics.

# The user is prompted to choose from 4 scheduling algorithms (1-4)
Available Scheduling Algorithms:
1. First-Come, First-Served (FCFS)
2. Shortest Job First (SJF) Non-Preemptive
3. Shortest Remaining Time First (SRTF) Preemptive
4. Round Robin (RR) Preemptive

If Round Robin is selected, then user must enter a time quantum
